# AppPromos V12.7.2 — Patch A
## Demo fuerte + combos precargados

## Objetivo
Fortalecer la demo para que el carnicero vea valor rápido sin tocar registro, web automática, tracking ni lógica profunda.

## Cambios incluidos

### Catálogo demo
- Se excluye cualquier producto cuyo nombre contenga `Pollo entero`.
- Se excluye cualquier producto cuyo nombre contenga `Hamburguesa`.
- Motivo: evitar confusión unidad/pieza/kilo y mantener la demo clara.

### Combos precargados demo
Se agregan 8 combos demo en `savedCombos` al correr el seeder:

1. Promo Parrillera de Hoy
2. Combo Familiar
3. Combo Económico
4. Promo para el Finde
5. Combo Mila Express
6. Combo Parrilla Completa
7. Combo Achuras
8. Combo Salvaventas

## Archivos modificados
- `public/js/data/seed-data.js`
- `public/js/modules/saved-module.js`
- `public/app.html`

## No toca
- Firebase/Auth profundo
- BusinessStore
- Registro
- Web automática
- Tracking
- Backend Python
- Bot WhatsApp

## Test mínimo
1. Abrir `seeder.html` y correr seeder.
2. Abrir app demo.
3. Verificar que no aparezcan productos `Pollo entero`.
4. Verificar que no aparezcan hamburguesas.
5. Ir a `Combos` y ver los 8 combos precargados.
6. Verificar que Crear/Armador sigue funcionando.
