# AppPromos V12.7.2 — Patch A.1
## Demo segura + WhatsApp en combos/ofertas

## Objetivo
Corregir el Patch A sin tocar registro ni web automática.

## Cambios

- El modo demo puede guardar ofertas creadas por el carnicero en `localStorage`, sin pisar `businesses/demo` en Firebase.
- Crear oferta agrega acción directa: `Guardar y mandar WhatsApp`.
- La pantalla `Combos` agrega botón `Enviar por WhatsApp` en cada combo precargado.
- El seeder renombra el botón a `Cargar demo + combos` y muestra cuántos combos cargó.

## No toca

- Registro
- Web automática
- Tracking
- Auth profundo
- BusinessStore profundo
- Backend Python
- Bot WhatsApp

## Test

1. Abrir `seeder.html`.
2. Apretar `Cargar demo + combos`.
3. Verificar log: `Combos: 8`.
4. Entrar a `app.html?demo=1`.
5. Abrir `Combos`.
6. Confirmar los 8 combos.
7. Enviar un combo por WhatsApp.
8. Crear oferta nueva.
9. Usar `Guardar y mandar WhatsApp`.
10. Confirmar que no se pisa Firebase demo con ofertas creadas por visitantes.
