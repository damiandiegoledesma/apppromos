# AppPromos V12.7.2-A.5 — Demo precios editables + WhatsApp limpio

## Objetivo
Cerrar el Patch A de demo fuerte sin tocar Firebase real ni registro.

## Cambios

- En modo demo, los cambios de precios/productos siguen guardándose en `localStorage`.
- Se agrega guard UX para reemplazar mensajes heredados tipo “Para guardar, ponete al día” por un mensaje de prueba segura.
- Se habilitan controles de guardado de demo si alguna vista los dejó deshabilitados por estado comercial.
- Se limpia el texto de WhatsApp de `Crear oferta` y `Combos` para evitar caracteres rotos (`�`).
- El texto final de WhatsApp usa saltos de línea, `Total:` separado y sin emojis riesgosos.

## No toca

- Registro.
- Web automática.
- Tracking.
- Backend Python.
- Bot WhatsApp.
- Firebase real para modo demo.

## Test mínimo

1. Abrir `app.html?demo=1` y hacer Ctrl+F5.
2. Ir a Cambiar precios.
3. Cambiar un precio y guardar.
4. Refrescar y verificar que el cambio queda en demo.
5. Confirmar que no aparece el bloqueo “Para guardar, ponete al día”.
6. Ir a Combos y enviar uno por WhatsApp.
7. Ir a Crear oferta, armar una oferta y enviarla por WhatsApp.
8. Confirmar que WhatsApp no muestra caracteres `�`.
9. Confirmar que Vender urgente sigue funcionando igual.
