# AppPromos V12.17-A2 — Web compacta y carrito de pedido completo

## Objetivo

Pulir la Web Arranque con carrito simple para que sea más útil para clientes reales de carnicería.

## Cambios

- Lista de productos por rubro más compacta.
- Carrito visual más ordenado.
- Pedido incluye teléfono del cliente.
- Pedido permite elegir:
  - Retiro en el local.
  - Envío con cadete.
- Si elige cadete, pide dirección.
- Pedido permite elegir:
  - Efectivo al recibir.
  - Transferencia.
- WhatsApp del pedido sale más completo y más claro.
- Corrección de textos visibles en el pedido.

## No incluye

- Pago online.
- Integración con Mercado Pago.
- Confirmación automática.
- Gestión de stock.
- Horarios de entrega.

## Testing mínimo

1. Abrir Web Arranque.
2. Agregar productos al pedido.
3. Agregar combos al pedido.
4. Completar nombre y teléfono.
5. Probar Retiro en local.
6. Probar Envío con cadete y dirección.
7. Probar Efectivo.
8. Probar Transferencia.
9. Enviar WhatsApp.
10. Validar mensaje final.
