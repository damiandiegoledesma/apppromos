# AppPromos — Personajes finales MVP

**Carniza vende. La Nelly cuida. AppPromos acompaña.**

Paquete mínimo para integrar identidad visual inicial en el repo.

## Archivos

```txt
public/assets/personajes/carniza/carniza-base-final.png
public/assets/personajes/carniza/carniza-avatar-final.png
public/assets/personajes/la-nelly/la-nelly-base-final.png
public/assets/personajes/la-nelly/la-nelly-avatar-final.png
```

## Uso recomendado

- Carniza base: card Inicio, demo, onboarding, landing.
- Carniza avatar: botón compacto, badge, header.
- La Nelly base: estados sensibles de acceso/pago.
- La Nelly avatar: alertas compactas, badges, tarjetas pequeñas.

## Textos guía

```txt
Carniza — Vendamos algo
La Nelly — Te cuida y nos cuida
```

```txt
Carniza aparece para vender.
La Nelly aparece para cuidar la continuidad.
```
