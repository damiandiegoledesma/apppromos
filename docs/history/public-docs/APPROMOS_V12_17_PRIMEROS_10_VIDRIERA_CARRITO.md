# AppPromos V12.17 — Primeros 10 carniceros reales

## Reenfoque total

AppPromos deja de venderse solo como una herramienta para armar ofertas por WhatsApp.

Nueva promesa principal:

> Tu carnicería online en minutos: vidriera automática + ofertas + carrito + pedidos por WhatsApp.

## Nuevo eje del producto

Antes:

Precios → Ofertas → WhatsApp

Ahora:

Precios → Vidriera online automática → Carrito/Pedidos → WhatsApp
+
Ofertas rápidas, combos y vender urgente

## Objetivo V12.17

Conseguir los primeros 10 carniceros reales.

No se busca agregar funciones por ansiedad. Se busca convertir mejor.

## 1. Web / Vidriera automática como gancho principal

La web deja de ser un extra escondido y pasa a ser el gancho comercial.

La web mínima debe tener:

- nombre/logo de carnicería;
- estado abierto/cerrado si existe;
- productos con precio real;
- productos sin precio real ocultos;
- ofertas destacadas;
- combos;
- botón agregar al carrito;
- carrito simple;
- datos del cliente;
- enviar pedido por WhatsApp.

No se implementa pago online ahora.

Cierre del pedido:

Cliente arma pedido → revisa carrito → toca WhatsApp → al carnicero le llega el pedido ordenado.

## 2. Carrito de compras

Primera versión simple:

- agregar producto;
- sumar/restar cantidad;
- eliminar producto;
- ver total estimado;
- pedir nombre del cliente;
- pedir dirección o aclaración opcional;
- enviar pedido por WhatsApp.

Mensaje esperado:

Hola, quiero hacer este pedido:

- 2 kg Asado
- 1 kg Chorizos
- 1 kg Picada común

Total estimado: $ 42.500

Nombre:
Dirección:
Aclaración:

## 3. Repensar Vender urgente

Vender urgente debe cambiar.

Nuevo criterio:

El carnicero elige qué productos quiere mover rápido y con qué productos arma el combo.

Flujo ideal:

1. Elegir productos a liquidar internamente.
2. Elegir productos acompañantes.
3. Definir precio final o descuento.
4. AppPromos arma combo vendedor.
5. Publicar en web.
6. Mandar por WhatsApp.

Regla de copy:

Internamente: urgencia.
Externamente: oportunidad.

No decir al cliente final:
- liquidación;
- producto atrasado;
- hay que sacarlo.

Decir:
- oferta del día;
- promo especial;
- combo de hoy;
- hasta agotar stock.

## 4. Landing nueva

La landing debe rediseñarse para convertir automáticamente.

Objetivo:

Que un carnicero real entienda en 10 segundos y quiera probar.

Estructura propuesta:

1. Hero:
   Tu carnicería online en minutos.
   Recibí pedidos por WhatsApp sin pagar comisión.

2. Demo visual:
   Vidriera + carrito + pedido entrando por WhatsApp.

3. Problema:
   Tenés precios, ofertas y clientes, pero todo queda desordenado en WhatsApp.

4. Solución:
   AppPromos te arma una web automática con carrito.

5. Cómo funciona:
   Cargás precios → publicás ofertas → recibís pedidos.

6. Oferta primeros 10:
   acompañamiento inicial + precio fundador.

7. CTA:
   Crear mi carnicería gratis.
   Probar demo.

## 5. Planes y precios

Hay que repensarlos.

Criterio nuevo:

Todos deben tener web propia.
El diferencial superior puede ser carrito/personalización/automatización.

Borrador inicial:

- Prueba gratis 30 días
- ARRANQUE: web propia + precios + pedidos por WhatsApp
- SALVADOR: arranque + ofertas + combos + vender urgente
- DUEÑO: salvador + carrito avanzado + web personalizada + más control

Pendiente:
definir precios reales para salir a vender a los primeros 10.

## Reglas de implementación

No romper:

- demo;
- registro;
- cambiar precios;
- crear oferta;
- WhatsApp premium;
- web por slug;
- productos con precio 0 ocultos;
- Panel Admin.

No abrir backend salvo necesidad real.

Primera etapa recomendada:

1. Diagnóstico de landing actual.
2. Diagnóstico de web actual.
3. Diseñar carrito simple para web.
4. Rediseñar landing.
5. Luego rediseñar Vender urgente.
