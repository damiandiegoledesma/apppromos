# APPPROMOS — ROADMAP REAL DESDE V11.4R

Fecha: 2026-04-26

## Criterio rector

AppPromos debe ser una herramienta móvil, rápida y confiable para carnicerías reales.

El cliente la usa mientras:
- atiende mostrador,
- cobra,
- responde WhatsApp,
- modifica precios,
- arma ofertas,
- trabaja con carne,
- y no tiene tiempo para pantallas confusas.

Por eso el roadmap prioriza:
1. Menos pasos.
2. Botones grandes.
3. Mensajes claros.
4. Guardados seguros.
5. Nada de sobreingeniería.
6. No romper Firebase ni resolveSession.

## FASE 2 — V11.4.1 Pruebas y ajuste fino de billing UX

Objetivo:
Validar que el usuario entienda el estado de su cuenta sin frustrarse.

Tareas:
- Revisar textos de aviso en móvil.
- Asegurar que el botón guardar muestre mensaje claro si no puede guardar.
- Evitar errores técnicos tipo permission denied en pantalla.
- Mostrar estado de Trial/Pago/Acceso de forma compacta en header.
- Agregar checklist manual de billing.

Regla UX:
Nunca mostrar una pantalla vacía por deuda. El cliente debe ver su información y entender qué acción necesita.

## FASE 5 — UX móvil operativa

Objetivo:
Hacer que AppPromos se sienta como una herramienta de mostrador, no como un sistema administrativo pesado.

Principios:
- Acciones principales siempre visibles.
- Menos texto largo en pantallas operativas.
- Guardar en 1 toque.
- Confirmaciones cortas.
- Botones grandes.
- Filtros simples.
- Evitar scroll innecesario.
- Vista clara del resultado antes de guardar/enviar.

Prioridad de módulos:
1. Crear oferta.
2. Precios.
3. WhatsApp.
4. Guardados.
5. Dashboard.
6. Competencia.
7. Web Premium.
8. Admin.
