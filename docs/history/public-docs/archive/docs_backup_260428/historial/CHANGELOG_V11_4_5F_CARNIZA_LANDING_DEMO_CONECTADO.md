# CHANGELOG — V11.4.5F Carniza Landing Demo Conectado

## Objetivo

Dejar la landing de AppPromos sin caminos muertos.

## Cambio incluido

- El botón `Probar demo` del formulario de registro ahora lleva al mismo flujo de registro/prueba gratis.
- No se crea una demo nueva.
- No se toca Web Premium.
- No se toca Carniza App.
- No se toca Firebase.

## Decisión de producto

Por ahora, la prueba real es con registro.

Más adelante puede desarrollarse una `Carnicería de Carniza` como demo controlada, solo lectura y sin guardado.
