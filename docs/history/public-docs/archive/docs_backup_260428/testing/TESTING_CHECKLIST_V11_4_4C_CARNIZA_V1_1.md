# TESTING CHECKLIST — V11.4.4C Carniza V1.1

## Flujo comercial

- [ ] Inicio: Carniza ofrece Precios / Ofertas, no WhatsApp directo.
- [ ] Precios: Carniza lleva a Ofertas.
- [ ] Ofertas: Carniza dice que primero hay que guardar la oferta.
- [ ] Ofertas: el botón dice `Ya la guardé: WhatsApp`.
- [ ] WhatsApp: Carniza indica elegir una oferta guardada.

## Estados comerciales

- [ ] Al día: mensajes vendedores y simples.
- [ ] Prueba: no confunde, empuja Precios / Ofertas.
- [ ] Por vencer: empuja Ofertas y consulta de planes, no WhatsApp directo.
- [ ] Pendiente: deriva a WhatsApp AppPromos.
- [ ] Pausado: deriva a WhatsApp AppPromos y mantiene Volver a Inicio.

## Seguridad / estabilidad

- [ ] No aparecen errores en consola.
- [ ] No rompe navegación entre paneles.
- [ ] No rompe bloqueo de guardado.
- [ ] No aparece lenguaje técnico.
- [ ] No aparecen frases internas tipo “dejá al cliente con salida clara”.
