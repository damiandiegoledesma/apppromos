# FUTURE — Carniza V2

## Idea

Carniza V2 puede empezar a mirar datos reales de la app para sugerir acciones comerciales.

## Posibles mejoras

- Detectar combos guardados.
- Sugerir una oferta rápida.
- Ayudar a armar mensaje de WhatsApp.
- Avisar si faltan precios.
- Recordar que hay ofertas sin enviar.

## Regla

Carniza puede sugerir, pero no debe guardar ni modificar datos sola.

## Python / IA

La integración con Python, FastAPI, Gemini, SQLite y WhatsApp API queda para una versión posterior.
