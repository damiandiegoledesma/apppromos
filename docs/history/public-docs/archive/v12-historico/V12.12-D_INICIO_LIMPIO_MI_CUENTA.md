# V12.12-D — Inicio limpio + Mi cuenta en Más

## Decisión UX

Inicio no debe mostrar la ficha grande de datos del negocio.

Ese contenido es útil, pero no es parte del flujo principal de venta. En mobile-first, Inicio debe estar reservado para acciones concretas:

```txt
Cambiar precios
Crear oferta
Enviar WhatsApp
Vender urgente
```

Los datos del negocio pasan a vivir en:

```txt
Más → Mi cuenta
```

## Regla de diseño

```txt
Inicio vende.
Más administra.
Mi cuenta guarda los datos.
```

## Cambios incluidos

- Se retira del cuerpo de Inicio la card **Datos del negocio activo**.
- Se mantiene Inicio con:
  - Inicio rápido.
  - Recorrido sugerido.
  - Resumen operativo.
- Se agrega un sheet/modal de **Mi cuenta** desde el menú mobile **Más**.
- Mi cuenta muestra:
  - Carnicería.
  - Responsable.
  - Email de acceso.
  - WhatsApp.
  - Dirección.
  - Localidad.
  - Plan.
  - Estado.
  - Mi web.
- Se permite editar datos básicos:
  - nombre comercial;
  - WhatsApp;
  - dirección;
  - ciudad.

## Qué no toca

- No toca registro.
- No toca Web de Arranque.
- No toca web pública.
- No toca lógica de precios.
- No toca lógica de ofertas.
- No toca WhatsApp.
- No toca Vender urgente.
- No toca Panel Admin profundo.
- No toca Firebase/Auth profundo.

## Criterios de aceptación

1. Inicio mobile carga limpio.
2. No aparece la card grande de datos del negocio en Inicio.
3. La botonera inferior sigue visible.
4. **Más → Mi cuenta** abre correctamente.
5. Mi cuenta muestra datos humanos de la carnicería.
6. Editar datos permite guardar cambios básicos.
7. Precios sigue abriendo.
8. Vender → Oferta rápida sigue funcionando.
9. Vender → Oferta con descuentos sigue funcionando.
10. Vender urgente → WhatsApp sigue funcionando.
11. WhatsApp sigue funcionando.
12. Salir demo / cerrar sesión sigue funcionando.

## Pendientes futuros

- Mejorar visualmente Mi cuenta en desktop/tablet si hace falta.
- Separar “Mi cuenta” de “Mi web” con más detalle cuando Web de Arranque crezca.
- Revisar si algunos datos comerciales deben ir al Panel Admin y no al cliente.
