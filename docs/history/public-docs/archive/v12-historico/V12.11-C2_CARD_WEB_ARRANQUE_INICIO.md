# V12.11-C2 — Card simple de Web de Arranque en Inicio

## Objetivo

Mostrar el efecto wow de la Web de Arranque dentro de Inicio, sin bloquear la app.

La versión V12.11-B ya logró que una carnicería nueva tenga web pública desde el registro. Esta versión agrega el paso comercial siguiente: que el carnicero lo vea y vaya directo a actualizar sus precios reales.

## Decisión de UX

El primer intento de V12.11-C quedó descartado porque generó una capa/overlay que oscurecía Inicio y podía dejar la pantalla colgada.

V12.11-C2 cambia el enfoque:

```txt
Nada de overlay.
Nada de modal.
Nada de capa oscura.
Nada de tocar Carniza flotante.
```

La solución es una card normal dentro del contenido de Inicio.

## Cuándo aparece

La card aparece cuando la carnicería tiene una Web de Arranque pendiente de precios reales.

Criterios:

```txt
web.mode = starter
web.priceListStatus = pending_real_prices
web.createdFrom = registration_auto
```

También contempla compatibilidad si alguno de esos campos está presente y todavía no se confirmó la lista de precios.

## Mensaje

```txt
Ya tenés tu web propia.

La dejamos preparada con tu nombre y tu WhatsApp.
Ahora actualizá tus precios reales y salís vendiendo.
```

La card también aclara:

```txt
Solo se publican productos con precio válido. Lo que no cargues, no aparece.
```

Esto refuerza la regla definida en V12.11-A:

```txt
La web pública no publica precios demo ni productos sin precio real.
```

## Acciones

### Actualizar mis precios

Lleva al módulo Cambiar precios.

Objetivo comercial: que el carnicero dé el primer paso fuerte de activación.

### Ver mi web

Abre la URL pública generada para la carnicería.

### Ocultar por ahora

Oculta la card durante la sesión usando `sessionStorage`.

No se guarda en Firestore para evitar escrituras innecesarias.

## Qué NO toca

- Registro.
- Web pública.
- Crear oferta.
- Oferta rápida.
- Oferta con descuentos.
- Vender urgente.
- WhatsApp.
- Panel Admin.
- Carniza flotante.
- La Nelly.
- Backend Python.
- SQLite.

## Criterios de aceptación

```txt
1. Inicio carga sin overlay oscuro.
2. La card aparece en empresa con Web de Arranque.
3. Actualizar mis precios abre Cambiar precios.
4. Ver mi web abre la web pública.
5. Ocultar por ahora oculta la card durante la sesión.
6. Crear oferta → WhatsApp sigue funcionando.
7. Vender urgente → WhatsApp sigue funcionando.
8. Panel Admin abre.
```

## Frase de producto

```txt
La Web de Arranque genera el wow.
Actualizar precios convierte ese wow en activación real.
```
