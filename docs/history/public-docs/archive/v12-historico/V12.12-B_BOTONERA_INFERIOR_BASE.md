# V12.12-B — Botonera inferior base

## Objetivo

Implementar la primera base real de navegación mobile-first para AppPromos.

La app deja de depender de acciones arriba de la pantalla en celular y suma una botonera inferior fija, pensada para Android gama media/entrada, uso con una mano y trabajo de mostrador.

## Botonera implementada

```txt
[Inicio] [Precios] [Vender] [WhatsApp] [Más]
```

## Comportamiento

### Inicio

Vuelve al tablero principal.

### Precios

Abre **Cambiar precios**.

### Vender

Abre un menú inferior con tres caminos comerciales:

- **Oferta rápida**: abre Crear oferta directamente en modo rápido.
- **Oferta con descuentos**: abre Crear oferta directamente en modo descuentos.
- **Vender urgente**: abre el flujo urgente de Carniza.

### WhatsApp

Abre el panel de WhatsApp.

### Más

Abre un menú inferior con:

- Mi cuenta.
- Mi web.
- Ofertas guardadas.
- Competencia.
- Ayuda.
- Panel Admin si corresponde.
- Salir demo / Cerrar sesión.

## Decisión UX

La botonera solo aparece visualmente en mobile.

En desktop/tablet grande se mantiene la navegación actual.

En mobile se oculta la navegación superior de módulos para evitar duplicación y dejar la acción principal al pulgar.

## Regla madre

```txt
La botonera mueve.
Carniza orienta.
El cuerpo vende.
```

## Qué toca

- `public/js/app-main.js`
- `public/js/modules/builder-module.js`
- documentación de versión

## Qué no toca

- Registro.
- Web de Arranque.
- Web pública.
- Cambiar precios lógico.
- Guardado de ofertas.
- WhatsApp lógico.
- Panel Admin profundo.
- Firebase/Auth.
- Backend.

## Criterios de aceptación

1. En mobile aparece la botonera inferior.
2. Inicio vuelve al tablero principal.
3. Precios abre Cambiar precios.
4. Vender abre menú con Oferta rápida, Oferta con descuentos y Vender urgente.
5. Oferta rápida abre Crear oferta en modo rápido.
6. Oferta con descuentos abre Crear oferta en modo descuentos.
7. Vender urgente abre el flujo urgente.
8. WhatsApp abre el panel de WhatsApp.
9. Más abre Mi cuenta, Mi web, Guardadas, Competencia, Ayuda, Admin si corresponde y Cerrar sesión.
10. Crear oferta → WhatsApp sigue funcionando.
11. Vender urgente → WhatsApp sigue funcionando.
12. En desktop no se rompe la navegación actual.
