# AppPromos V12.9.4 — Fix catálogo Oferta rápida

## Objetivo
Evitar que Oferta rápida quede limitada a muy pocos productos después de los ajustes de UX Mostrador.

## Criterio
El carnicero no puede vender solo 5 productos. Tiene que poder encontrar cualquier producto rápido, sin volver al mar de botones.

## Cambios

1. Oferta rápida deja de tener un límite duro bajo de productos.
2. Oferta con descuentos usa el mismo criterio de catálogo filtrable.
3. Se agrega carga progresiva:
   - muestra un lote inicial compacto;
   - permite tocar “Ver más productos”;
   - búsqueda y rubros siguen disponibles.
4. El catálogo acepta productos con campos `precio` o `price`, y nombres con `nombre` o `name`.
5. No toca WhatsApp, Vender urgente, Cambiar precios, Promos ni flujo de cache ya corregido.

## Regla UX

Más productos disponibles, pero sin inundar la pantalla.
