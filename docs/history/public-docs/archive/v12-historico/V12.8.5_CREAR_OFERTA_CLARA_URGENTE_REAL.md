# V12.8.5 — Crear Oferta clara + Demo limpia + Urgente real

## Objetivo

Bajar la complejidad visual de Crear Oferta y hacer que Vender urgente use el catálogo real/demo disponible, no una lista limitada fija.

## Cambios

1. Demo limpia:
   - Se oculta el acceso a Competencia en modo demo.
   - La demo queda enfocada en probar venta, oferta y WhatsApp.

2. Productos elegidos más visibles:
   - En Oferta rápida se muestra arriba un resumen vivo de productos elegidos.
   - En Oferta con descuentos también se muestra arriba la selección actual.

3. Descuentos más claros:
   - Se evita el lenguaje “ahorro”.
   - Se usa “Descuento” y “Descuentos aplicados”.
   - Cada producto muestra: Antes / Descuento / Queda.
   - El cuadro vivo muestra: total sin descuentos, descuentos aplicados y total final.

4. Vender urgente real:
   - Carniza toma productos desde el catálogo activo cargado en la sesión.
   - Se agregan chips de rubro y búsqueda.
   - Se amplía la lista visible para evitar que parezcan siempre los mismos productos.

## No toca

- WhatsApp final.
- Redondeo validado.
- Guardar para repetir.
- Firebase/Auth/BusinessStore profundo.
- Carniza contextual general.

## Criterio UX

Menos tablero. Más mostrador.

El carnicero debe ver rápido:
- qué eligió;
- cuánto descontó;
- cuánto queda;
- cuánto va a mandar por WhatsApp.
