# AppPromos V12.18-E1 — Carniza activación contextual

## Filosofía
Carniza no ocupa pantalla explicando. Lee el estado de la carnicería y ofrece el siguiente paso.

Orden:
1. Web / precios.
2. Identidad (logo + frente).
3. Venta.

## Estados
- Sin precios/web: “Cargá tus primeros precios.”
- Web incompleta: “Terminemos tu vidriera.”
- Sin logo/foto: “Dale tu identidad.”
- Activada: vuelve a “Vendamos algo”.
- Precios/Ofertas/WhatsApp: mensajes cortos y contextuales.

## UX mobile
- Panel más compacto.
- Menos texto.
- Máximo dos acciones.
- Footer explicativo oculto en mobile.

## No cambia
- AccessControl / La Nelly.
- Firebase/Auth/Storage.
- Precios.
- Ofertas.
- WhatsApp.
- Web pública.
- D3 Inicio.
- Tracking del tercer login (queda para hito propio).
