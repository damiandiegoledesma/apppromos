# AppPromos V12.18-D3 — Inicio UX/UI mobile-first

## Objetivo
Reducir texto permanente en Inicio y llevar la pantalla a una lógica de mostrador:
acciones reconocibles en segundos, iconos grandes y poco consumo vertical.

## Cambios
- Título: “¿Qué querés hacer?”
- Cuatro acciones principales: Mi carnicería / Precios / Crear oferta / WhatsApp.
- En mobile: grilla 2x2.
- Los textos explicativos de las cuatro tarjetas dejan de ocupar pantalla.
- Se elimina del Inicio el bloque permanente “La regla es simple”.
- Acciones secundarias compactas: Compartir web / Gestionar mi web.

## No cambia
- Navegación ni data-action-panel.
- Web pública D2.
- Precios.
- Ofertas.
- WhatsApp.
- Carrito.
- Firebase/Auth/Storage/Firestore.
- Carniza.
