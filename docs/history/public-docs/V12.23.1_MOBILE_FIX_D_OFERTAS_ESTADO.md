# AppPromos V12.23.1 — Mobile Fix D

## Alcance

Parche incremental para la vidriera pública. Debe copiarse sobre `C:\apppromos`.

Archivos incluidos:

- `public/web.html`
- `public/docs/V12.23.1_MOBILE_FIX_D_OFERTAS_ESTADO.md`

No modifica Firebase, Firestore, `resolveSession`, reglas de acceso, billing ni datos guardados.

## Cambios

### D1 — Nombres descriptivos

Las Ofertas de hoy con nombres genéricos como `OFERTA DEL DÍA` o `Promo del día` reciben un nombre público construido a partir de sus componentes.

Ejemplos:

- `2 kg de Picada Común`
- `Picada y Costeletas`
- `Combo del día: Pollo, Bondiola y Costeletas`

Los nombres comerciales existentes se conservan. La resolución se realiza en `web.html` y no modifica Firestore.

El mismo nombre público se utiliza en:

- tarjeta de la oferta;
- carrito;
- mensaje de WhatsApp;
- atributos accesibles del botón para agregar.

Los ítems de tipo `daily_offer` que ya estaban en el carrito también se actualizan en memoria cuando es posible vincularlos con una oferta activa.

### D2 — Textos simplificados

- Encabezado: `Ofertas de hoy`.
- Subtítulo: `Hasta agotar stock`.
- Se eliminó la cinta `SOLO POR HOY`.
- Se eliminó `Válidas hoy`.
- Se eliminó la repetición de `Hasta agotar stock` dentro de cada tarjeta.

### D3 — Navegación inferior

La etiqueta `Del día` fue reemplazada por `Hoy`. Se conserva el icono de fuego y el destino `#ofertas-dia`.

### D4 — Estado del comprador

Durante la sesión se conservan:

- texto del buscador;
- rubro seleccionado;
- resultados derivados de ambos filtros;
- posición aproximada de desplazamiento.

La clave utiliza el formato `apppromos_web_view_<tenant>` y queda separada por `businessId`, slug o nombre normalizado de la carnicería.

No se guardan nombre, teléfono, dirección, forma de entrega ni medio de pago en este estado.

La posición se restaura después del render. Si la URL contiene un destino explícito con `#`, ese destino tiene prioridad y no se fuerza la posición anterior.

## Instalación local

1. Cerrar el servidor local si estuviera usando archivos bloqueados.
2. Extraer el ZIP directamente sobre `C:\apppromos`.
3. Confirmar la combinación o reemplazo de los dos archivos incluidos.
4. Iniciar el entorno local habitual.
5. Abrir la vidriera con parámetro anticaché, por ejemplo:

   `http://127.0.0.1:5000/web.html?slug=SLUG_DE_LA_CARNICERIA&v=fix-d`
