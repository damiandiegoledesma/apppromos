# AppPromos V12.23.1 — QA A La Estaca 04

## Vidriera pública

- Se separan Productos, Promos y Ofertas del día como destinos independientes.
- Se agregan tres botones visibles de navegación comercial.
- El filtro de Promos se muestra también en desktop.
- Se conserva el selector de rubros de Productos.
- Se agrega un carrusel con hasta diez productos con imagen real elegidos al azar.
- No se muestran promociones con imágenes genéricas para evitar confundir al comprador.
- Las tarjetas no repiten las etiquetas "Producto" o "Promo": muestran nombre y precio.
- Al elegir una tarjeta, se abre su rubro, se baja hasta el producto exacto y se lo destaca visualmente.
- Se eliminan los tres botones repetidos debajo del encabezado.
- La navegación inferior queda disponible en mobile y desktop con Productos, Promos, Ofertas del día, Carrito y WhatsApp.
- El carrusel avanza automáticamente cada cinco segundos y tiene controles manuales.
- Cada tarjeta del carrusel dirige a la sección correspondiente.
- Se conserva el carrito y el envío del pedido por WhatsApp.

## QA local sugerido

1. Abrir la vidriera pública local con recarga forzada.
2. Verificar los tres botones y sus destinos.
3. Probar el filtro de Promos y el selector de rubros de Productos.
4. Comprobar el avance automático y los botones del carrusel.
5. Agregar un producto y una promo al carrito y revisar el pedido.
