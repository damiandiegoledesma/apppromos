## Mensajes comerciales base

### Prueba gratis 30 días
Probás AppPromos 30 días y ya tenés tu web propia de arranque.

### ARRANQUE
Vendés rápido por WhatsApp y tenés tu web básica para mostrar la carnicería.

### SALVADOR
Vendés antes de picar, cuidás margen y mantenés tu web activa.

Mensaje fuerte:

```txt
No mandes cortes buenos a la picadora.
Salvador te ayuda a venderlos antes de que pierdas.
```

### DUEÑO
Mirás mercado, cuidás precios y personalizás tu web como vidriera profesional.

## Regla comercial

```txt
Todos los planes tienen web propia.
DUEÑO tiene web personalizada.
SALVADOR es el plan recomendado.
```

## Nota visual

La pieza `plan-salvador-dark-dorado.png` es la pieza de mayor impacto visual del set.
Debe usarse para captar atención, cortar el scroll y empujar el plan recomendado.

El dorado no debe comunicar lujo vacío; debe comunicar valor recuperado:

```txt
No perder margen.
No mandar cortes buenos a la picadora.
Vender antes de perder.
```
