# V12.13-B-FIX1 — Resumen de descuentos sobre Carniza

## Motivo

Durante el test mobile de **V12.13-B — Oferta con descuentos mobile compacta**, el flujo funcional pasó correctamente, pero se detectó un solapamiento visual:

```txt
Carniza tapa el total con descuento.
```

Como el total final es un dato clave para decidir si la promo sirve, no debe quedar tapado por Carniza ni por la botonera inferior.

## Cambios

- Se eleva el resumen flotante de **Oferta con descuentos** por encima de Carniza.
- Se aumenta el espacio inferior de la pantalla de ajuste de descuentos.
- Se mantiene la pantalla compacta mobile-first sin volver a una grilla ancha.

## No toca

- Oferta rápida.
- Vender urgente.
- WhatsApp.
- Guardado.
- Redondeo.
- Cálculo de descuentos.
- Registro/Login.
- Web pública / Web de Arranque.
- Panel Admin.
- Firebase/Auth profundo.

## Test recomendado

1. Abrir app en mobile.
2. Vender → Oferta con descuentos.
3. Agregar 2 o 3 productos.
4. Ir a Ajustar descuentos.
5. Confirmar que Carniza no tapa el total final del resumen.
6. Usar `−` / `+` en descuento individual.
7. Usar `−` / `+` en descuento general.
8. Confirmar que el resumen se actualiza.
9. Ver oferta lista.
10. Enviar por WhatsApp OK.
11. Oferta rápida → WhatsApp OK.
12. Vender urgente → Oferta lista → WhatsApp OK.
