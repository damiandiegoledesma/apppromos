# V12.8.3 — Crear Oferta foco real + Carniza contextual limpio

## Objetivo

Ajustar V12.8.2 después del testing real para que Crear Oferta se sienta más simple, visible y controlable.

## Cambios

1. Se elimina el mensaje interno de desarrollo del paso inicial.
2. Todas las pantallas de Crear Oferta tienen salida directa a Inicio.
3. En selección de productos se muestran los productos elegidos en vivo.
4. La selección de productos evita mostrar todo junto y mantiene buscador + rubros + lista compacta.
5. Oferta rápida mantiene redondeo a centena.
6. Oferta con descuentos muestra una vista previa en vivo de cómo va quedando la oferta.
7. Carniza usa acciones contextuales reales según el paso actual.
8. Desde Inicio, Carniza ofrece:
   - Oferta rápida.
   - Oferta con descuentos.
   - Vender urgente.
9. En Crear Oferta, Carniza deja de mostrar botones que no corresponden al paso.
10. Al volver a Inicio se limpia el modo foco para que reaparezcan header, navegación y footer.

## Criterio UX

- Modo foco no es esconder todo solamente.
- Modo foco es dejar al carnicero viendo exactamente lo que necesita para vender.
- Una pantalla, una intención, una acción clara.
- Carniza ayuda desde afuera, no ocupa la pantalla principal.
- Siempre tiene que existir forma clara de volver o salir.

## No toca

- Firebase.
- Auth.
- BusinessStore.
- Demo localStorage.
- Vender urgente.
- WhatsApp del liquidador.
- Lógica base de descuentos.

5. Oferta rápida: agregar productos y verlos en vivo abajo.
6. Oferta rápida: revisar total redondeado.
7. Oferta rápida: WhatsApp abre y no guarda automático.
8. Guardar para repetir funciona.
9. Volver a Inicio desde cualquier paso.
10. Header/nav/footer reaparecen al salir de Crear Oferta.
11. Oferta con descuentos: agregar productos.
12. Ajustar kilos/descuentos y ver preview vivo.
13. WhatsApp final no muestra descuentos explícitos.
14. Carniza en Crear Oferta muestra solo acciones del paso actual.
15. Carniza desde Inicio muestra Oferta rápida, Oferta con descuentos y Vender urgente.
16. Vender urgente sigue funcionando.
