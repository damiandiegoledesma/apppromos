# V12.8.8 — Guardado solo para promos con descuento

## Objetivo
Evitar que AppPromos genere un archivo gigante de ofertas descartables.

## Regla principal

```txt
Lo rápido se manda.
Lo urgente se resuelve.
Lo promocional se guarda.
```

## Cambios

1. Oferta rápida ya no muestra botón de guardado.
2. Oferta rápida solo permite enviar por WhatsApp, volver y ajustar o volver a inicio.
3. Vender urgente se mantiene como acción del momento, sin guardado promocional.
4. Oferta con descuentos mantiene guardado, pero ahora como `Guardar como promo`.
5. El guardado queda protegido: si algo intenta guardar una oferta que no sea con descuento, se bloquea con mensaje humano.
6. Las promos con descuento se guardan con metadata simple: `tipo: promo_con_descuento`, `savedAs: promo`, `isPromotional: true`, `status: active`.

## No toca

- WhatsApp.
- Redondeo.
- Vender urgente.
- Resumen flotante.
- Demo localStorage.
- Firebase/Auth.

## Pendiente futuro

Limpiar ofertas guardadas viejas generadas durante testing y/o agregar archivo/archivado de promos antiguas.
