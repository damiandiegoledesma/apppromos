# AppPromos V12.9.6 — Unificar catálogo de productos

## Objetivo

Corregir la diferencia entre módulos:

- Cambiar precios veía el catálogo completo.
- Crear oferta veía una lista reducida de 5 productos.

## Regla aplicada

> Los sugeridos son una vista. El catálogo completo es la fuente.

## Cambios

1. `app-main.js` mantiene una fuente activa única de productos (`currentActiveProducts`).
2. Crear oferta usa el mismo catálogo activo que Cambiar precios.
3. Oferta rápida puede mostrar 5 sugeridos al inicio, pero búsqueda/rubros trabajan sobre el catálogo completo.
4. Oferta con descuentos también usa el catálogo completo.
5. Carniza/Vender urgente lee el catálogo activo.
6. Se preserva el lenguaje de V12.9.5:
   - “Sugeridos para arrancar”
   - “Sumar”
   - “Ver oferta lista”
