# AppPromos V12.13-C5-FIX2 — Pulido visual Web Arranque

## Objetivo

Pulido menor posterior a producción C5 para mejorar la lectura visual de la Web Arranque pública.

## Cambios

- Se agrandó y reforzó el sello de AppPromos al pie de la vidriera pública.
- Se cambió el asset del sello para usar el logo cuadrado de AppPromos, más visible que el lockup horizontal con aire interno.
- Se mejoró la jerarquía de los títulos de rubros/categorías en la lista de precios.
- Los rubros ahora se ven como encabezados de categoría, con más tamaño, color AppPromos y separación.

## No toca

- No toca precios vivos.
- No toca regla de precio 0.
- No toca slug ni publicWebSlugs.
- No toca WhatsApp.
- No toca Mi cuenta / Mi Web.
- No toca registro/login.
- No toca Firebase/Auth.

## Test recomendado

1. Abrir una Web Arranque pública por slug.
2. Verificar que el sello AppPromos al pie se vea más claro.
3. Verificar que los rubros como Cerdo, Pollo, Novillo, etc. destaquen sobre los productos.
4. Confirmar que la lista de precios sigue compacta y legible.
5. Confirmar que WhatsApp, precios vivos y precio 0 siguen funcionando igual.
