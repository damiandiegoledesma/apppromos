# V12.12-D-FIX1 — Inicio autoresponsive mobile

## Objetivo

Corregir el desborde visual detectado en mobile al volver a Inicio después de implementar **V12.12-D — Inicio limpio + Mi cuenta en Más**.

El problema observado fue:

```txt
Inicio todavía no se adaptaba del todo al ancho del celular.
La botonera inferior podía verse más ancha que la pantalla.
Carniza podía quedar fuera del área cómoda visible.
```

## Criterio UX

AppPromos debe diseñarse para celulares Android gama media/entrada usados por carniceros argentinos, con uso vertical y una mano.

Regla aplicada:

```txt
Inicio entra completo.
Botonera entra completa.
Carniza queda adentro.
El centro sigue vendiendo.
```

## Cambios aplicados

- Se agrega protección contra overflow horizontal en mobile.
- Se asegura que `body`, `.app` y `.panel` no generen ancho mayor al viewport.
- Se ajusta la botonera inferior para respetar el ancho real de pantalla.
- Se ajusta Carniza para quedar visible dentro del viewport, arriba de la botonera.
- Se compactan cards y acciones de Inicio en mobile.
- Se eliminan anchos mínimos que podían empujar botones fuera de pantalla.

## Qué se mantiene

- **Más → Mi cuenta** sigue funcionando como lugar de datos del negocio.
- Inicio sigue limpio, sin la card de “Datos del negocio activo”.
- Botonera inferior sigue siendo la navegación principal mobile.
- Carniza sigue como ayuda flotante.
- Precios, Crear oferta, WhatsApp y Vender urgente no cambian de lógica.

## No toca

- Registro.
- Web de Arranque.
- Web pública.
- Firebase/Auth.
- Lógica de precios.
- Lógica de ofertas.
- Lógica de WhatsApp.
- Panel Admin profundo.

## Test recomendado

```txt
1. Inicio mobile carga limpio.
2. Pulsar Inicio desde la botonera inferior.
3. Confirmar que la pantalla no se ensancha ni aparece scroll horizontal.
4. Confirmar que la botonera inferior entra completa en pantalla.
5. Confirmar que Carniza queda visible arriba de la botonera.
6. Más → Mi cuenta abre correctamente.
7. Precios abre correctamente.
8. Vender → Oferta rápida → WhatsApp OK.
9. Vender → Oferta con descuentos OK.
10. Vender urgente → WhatsApp OK.
11. Salir demo / cerrar sesión OK.
```
