# V12.12-B-FIX4 — Oferta rápida: acción visible arriba del listado

## Objetivo

Corregir el test mobile de Oferta rápida: el resumen ya aparecía dentro del flujo, pero el botón de acción **Ver oferta lista** no quedaba visible donde el carnicero lo necesita.

## Decisión UX

La acción principal de Oferta rápida debe aparecer junto al resumen, antes del listado largo de productos.

```txt
Oferta rápida = elegir productos → ver oferta lista → mandar WhatsApp.
```

Si el carnicero ya eligió productos, no debe scrollear ni buscar el botón para avanzar.

## Cambios

- El resumen de Oferta rápida queda como tarjeta sticky al inicio del flujo.
- El botón **Ver oferta lista** aparece dentro de esa tarjeta, antes del buscador y de la grilla de productos.
- Se elimina la dependencia de una barra inferior propia para Oferta rápida.
- Se evita competir con la botonera inferior mobile.
- Mantiene Carniza por encima de la botonera.

## No toca

- Registro.
- Web de Arranque.

- Lógica de precios.
- Lógica de WhatsApp.
- Vender urgente.
- Oferta con descuentos.

## Test mínimo

1. Abrir app en mobile.
2. Confirmar que la botonera inferior sigue visible.
3. Confirmar que Carniza queda arriba de la botonera.
4. Ir a Vender → Oferta rápida.
5. Agregar productos.
6. Confirmar que el resumen y **Ver oferta lista** se ven arriba del listado.
7. Entrar a **Ver oferta lista**.
8. Confirmar que **Enviar por WhatsApp** se puede tocar.
9. Enviar WhatsApp OK.
10. Confirmar que Oferta con descuentos sigue OK.
11. Confirmar que Vender urgente sigue OK.
