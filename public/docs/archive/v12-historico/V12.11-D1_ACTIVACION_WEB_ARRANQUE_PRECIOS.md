# V12.11-D1 — Activación Web de Arranque: guía para precios

## Objetivo

V12.11-D1 mejora el paso posterior al efecto wow de la Web de Arranque.

La web ya nace desde el registro, pero el carnicero necesita una instrucción simple para completar lo más importante:

```txt
Actualizar sus precios reales.
```

La regla de producto queda:

```txt
A los productos que no vendés, poneles 0.
AppPromos no los muestra en tu web.
```

## Por qué importa

El catálogo base de AppPromos puede tener más productos que los que vende cada carnicería.

Si el carnicero siente que tiene que configurar todo antes de usar la app, aumenta la fricción.

La solución simple es:

- si vende un producto, le carga precio real;
- si no lo vende, le pone 0;
- los productos con precio 0 no aparecen en la web pública.

## Decisión UX tomada después del test

La card de Web de Arranque en el cuerpo de Inicio funcionó, pero no quedó como solución definitiva.

Motivo:

```txt
El cuerpo principal de la app debe mantener foco en vender:
Cambiar precios → Crear oferta → WhatsApp.
```

Por eso, V12.11-D1 deja como cambio estable el tip en **Cambiar precios** y retira el aviso/card del cuerpo de Inicio.

El aviso de Web de Arranque queda para una próxima versión como mensaje contextual dentro de Carniza, sin overlay bloqueante.

## Qué cambia

### Cambiar precios

Se agrega un tip visible:

```txt
Tip para tu web:
Cargá precio solo en los productos que vendés.
Si no vendés un producto, ponelo en 0 y no aparecerá publicado.
```

### Inicio

Se retira el aviso/card de Web de Arranque del cuerpo principal para no competir con el flujo central de venta.

## Qué no cambia

No se toca:

- registro;
- Web de Arranque;
- web pública;
- Crear oferta;
- Oferta rápida;
- Oferta con descuentos;
- Vender urgente;
- WhatsApp;
- Panel Admin;
- backend;
- SQLite.

## Criterios de aceptación

1. Inicio carga sin pantalla oscura.
2. Inicio no muestra card grande de Web de Arranque en el cuerpo principal.
3. Cambiar precios muestra el tip para la web.
4. Crear oferta → WhatsApp sigue funcionando.
5. Vender urgente → WhatsApp sigue funcionando.
6. Panel Admin abre.
