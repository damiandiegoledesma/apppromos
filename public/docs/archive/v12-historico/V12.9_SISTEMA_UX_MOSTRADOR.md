# AppPromos V12.9 — Sistema UX Mostrador

## Objetivo
Aplicar una regla global de interfaz: AppPromos no debe sentirse como planilla ni formulario administrativo. Debe sentirse como un mostrador digital: rápido, claro y con menos scroll.

## Regla madre

> AppPromos no es una planilla. Es un mostrador digital.

## Cambios incluidos

1. **Crear Oferta / Oferta con descuentos**
   - Los productos pasan de tarjetas altas a filas compactas.
   - Cada producto muestra en una línea de trabajo: producto, cantidad, base, descuento, queda final y quitar.
   - Se corrige el texto de descuento por producto para evitar valores negativos cuando el redondeo sube a la centena.
   - Se mantiene el Resumen flotante.

2. **Oferta rápida**
   - La revisión de productos queda más compacta.
   - Se mantiene el resumen flotante y la regla de no guardar automáticamente.

3. **Cambiar precios**
   - La lista de precios pasa a filas más compactas.
   - Producto, precio actual, nuevo precio y acciones quedan más cerca.
   - Menos alto por producto, menos scroll y más lectura rápida.

4. **Promos guardadas**
   - Se renombra visualmente como “Promos guardadas”.
   - Se presenta como lista compacta de promos para repetir, no como archivo gigante.
   - Botón “Enviar” más directo.

## Criterios UX aprobados

- Una acción importante = una pantalla simple.
- Un producto = una fila clara.
- Un cálculo = resumen flotante.
- Filas compactas antes que tarjetas gigantes.
- En flujos comerciales siempre debe existir volver/inicio/acción principal.
- Carniza ayuda sin tapar.
- Nada de mensajes internos o técnicos en la UI.
- Lo rápido se manda.
- Lo urgente se resuelve.
- Lo promocional se guarda.

## No toca

- Firebase/Auth.
- BusinessStore profundo.
- WhatsApp.
- Guardado inteligente ya validado.
- Vender urgente.
- Carniza contextual.
