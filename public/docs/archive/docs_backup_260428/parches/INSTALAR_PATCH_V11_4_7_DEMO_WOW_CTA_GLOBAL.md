# INSTALAR PATCH — V11.4.7 DEMO WOW CTA GLOBAL

## Instalación
Copiar y reemplazar los archivos incluidos en el ZIP respetando las rutas.

## Archivos principales
- `public/index.html`
- `public/js/app-main.js`
- `public/js/data/demo-business-data.js`
- `public/js/modules/access-gate-module.js`
- `public/js/modules/auth-module.js`
- `public/js/services/auth-service.js`
- `public/js/services/business-service.js`
- `public/js/services/write-guard-service.js`
- docs en `public/docs/`

## Prueba rápida
1. Levantar emulador/hosting local.
2. Abrir landing.
3. Tocar “Probar demo”.
4. Confirmar que entra a `/app.html?demo=1`.
5. Armar una oferta y verificar que no permita guardar.
