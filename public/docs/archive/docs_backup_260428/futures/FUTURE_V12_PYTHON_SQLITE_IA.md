# FUTURE — V12 Python + SQLite + IA

## Objetivo
Convertir a Carniza en un ayudante comercial con memoria local, cache y recomendaciones.

## Base técnica prevista
- Backend Python separado del frontend Firebase.
- FastAPI + Uvicorn.
- SQLite para memoria/cache local.
- `.env` para claves de IA.
- Google GenAI / Gemini.

## Posibles funciones
- Responder dudas frecuentes sin llamar siempre a IA.
- Recordar patrones comerciales.
- Sugerir combos según precios.
- Armar mensajes de WhatsApp más vendedores.
- Evitar caídas por exceso de llamadas a IA.
