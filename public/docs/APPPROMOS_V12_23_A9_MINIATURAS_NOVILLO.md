# AppPromos V12.23-A9 — Piloto de miniaturas Novillo

## Objetivo

Validar la incorporación de fotografías transparentes de cortes antes de
completar los demás rubros.

## Alcance

- 32 imágenes de Novillo aportadas desde Canva.
- Conversión a WebP transparente de 320 × 320 px.
- Imagen centrada sin deformación.
- Miniaturas en Precios.
- Miniaturas en la selección de productos para consultas y promos.
- Miniaturas en la lista de precios de la web pública.
- Carga diferida y ocultamiento seguro si un archivo no está disponible.
- Resolución por ID estable con respaldo por nombre para productos propios.

## Correspondencias aprobadas

- `costilla.webp`: Asado Banderita, Asado Costilla y Asado del Medio.
- `cima.webp`: Falda Deshuesada.
