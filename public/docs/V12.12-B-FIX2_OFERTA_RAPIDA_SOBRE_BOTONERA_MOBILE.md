# V12.12-B-FIX2 — Oferta rápida sobre botonera mobile

## Objetivo

Corregir el solapamiento detectado en mobile después de implementar la botonera inferior base.

En el test de V12.12-B-FIX1 se validó que Carniza ya queda por encima de la botonera, pero se detectó que en **Oferta rápida** la barra inferior seguía pisando el botón para revisar o mandar la oferta.

## Problema detectado

En mobile conviven dos elementos inferiores:

```txt
Resumen flotante de Oferta rápida
Botonera inferior mobile
```

La botonera no puede tapar acciones comerciales críticas.

## Corrección aplicada

- Se sube el resumen flotante de Oferta rápida con una variable específica:

```txt
--apppromos-mobile-quick-summary-bottom
```

- Se aumenta el espacio inferior del listado de productos de Oferta rápida.
- Se agrega margen inferior a la pantalla final de revisión para que **Enviar por WhatsApp** quede accesible.

## Criterio UX

```txt
Oferta rápida es camino sagrado.
El carnicero tiene que poder revisar y mandar sin que la barra inferior tape la acción.
```

## No toca

- Lógica de WhatsApp.
- Vender urgente.
- Oferta con descuentos.
- Registro.
- Web de Arranque.
- Panel Admin.
- Firebase/Auth.

## Test mínimo

1. Abrir app en mobile.
2. Confirmar que la botonera inferior sigue visible.
3. Ir a **Vender → Oferta rápida**.
4. Agregar productos.
5. Confirmar que **Ver oferta lista** no queda tapado.
6. Entrar a la revisión.
7. Confirmar que **Enviar por WhatsApp** no queda tapado.
8. Probar **Enviar por WhatsApp**.
9. Probar **Vender urgente → WhatsApp** para confirmar que sigue intacto.
