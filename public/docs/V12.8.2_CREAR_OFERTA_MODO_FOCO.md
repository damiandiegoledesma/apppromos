# V12.8.2 — Crear Oferta Modo Foco

## Objetivo

Convertir **Crear Oferta** en un flujo de venta guiado, limpio y escalable:

```txt
Un paso, una decisión, un botón fuerte.
```

## Cambios aplicados

### 1. Modo foco en Crear Oferta

Al entrar a Crear Oferta se ocultan elementos que no ayudan a resolver la acción:

- header grande;
- navegación principal;
- footer;
- marcos visuales externos.

Queda una pantalla limpia para resolver la tarea actual.

### 2. Flujo por pantallas

Crear Oferta deja de sentirse como formulario largo y pasa a funcionar como camino guiado.

#### Oferta rápida

```txt
1. Elegir modo
2. Elegir productos
3. Revisar kilos y total
4. Oferta lista / WhatsApp
```

#### Oferta con descuentos

```txt
1. Elegir modo
2. Elegir productos
3. Ajustar kilos y descuentos
4. Oferta lista / WhatsApp
```

Cada paso mantiene salida clara:

- volver;
- seguir;
- guardar para repetir;
- enviar por WhatsApp.

### 3. Selector de productos escalable

Se reemplaza la lógica de selector/formulario por una pantalla pensada para 200 o 300 productos:

- buscador protagonista;
- “Más usados” primero;
- rubros como chips horizontales;
- productos en lista compacta;
- no se muestran todos los productos juntos;
- barra inferior con productos elegidos y acción siguiente.

Esto deja el modelo preparado para otros rubros futuros:

- verdulerías;
- almacenes;
- kioscos;
- pollerías;
- otros comercios.

### 4. Redondeo en Oferta rápida

Oferta rápida ahora redondea el total final a la centena, igual que Oferta con descuentos.

Criterio:

```txt
Evitar totales raros.
Usar totales vendibles.
```

### 5. WhatsApp no guarda automáticamente

Enviar por WhatsApp no guarda la oferta por defecto.

Guardar queda como decisión aparte:

```txt
Guardar para repetir
```

Criterio comercial:

```txt
No todas las ofertas merecen quedar archivadas.
Guardar solo lo reutilizable.
```

### 6. Carniza contextual sin duplicar botón

No se crea un nuevo Carniza.

Se usa el botón existente y se actualiza su contexto según el paso:

- elegir modo;
- elegir productos;
- revisar kilos;
- ajustar descuentos;
- oferta lista.

Carniza ayuda desde su tarjetita/globo, no dentro del cuerpo principal.

Regla:

```txt
Carniza ayuda, no tapa.
```
