# V12.11-D2 — Carniza navegación segura

## Objetivo

Este ajuste mejora el menú de Carniza para que siempre ayude al carnicero a orientarse.

Carniza no debe ser solo un botón para vender. También debe permitir volver a Inicio o salir/cerrar sesión sin que el usuario se pierda.

## Problema detectado

En mobile, el carnicero puede abrir Carniza y necesitar volver rápido al inicio o salir de la app.

Si esas acciones no están disponibles, aparece fricción:

```txt
¿Y ahora cómo vuelvo?
¿Cómo cierro?
¿Cómo salgo de la demo?
```

Eso va contra el criterio de AppPromos:

```txt
La app tiene que trabajar sola y no dejar encerrado al carnicero.
```

## Decisión UX

El menú de Carniza debe incluir siempre:

- Armar oferta.
- Vender urgente.
- Ir a WhatsApp.
- Volver a Inicio.
- Salir de la demo / Cerrar sesión.

## Comportamiento

### Usuario en demo

El menú muestra:

```txt
Salir de la demo
```

La acción vuelve a la landing.

### Usuario logueado

El menú muestra:

```txt
Cerrar sesión
```

La acción cierra sesión y vuelve a la landing.

### Volver a Inicio

La acción cierra el panel de Carniza y lleva al panel principal de Inicio.

## Reglas de alcance

Este patch no modifica:

- Registro.
- Web de Arranque.
- Web pública.
- Cambiar precios.
- Crear oferta.
- Vender urgente.
- WhatsApp.
- Panel Admin.

## Criterio mobile-first

Este ajuste prepara el camino para una futura navegación mobile-first con botonera inferior.

Regla nueva:

```txt
Carniza orienta.
La navegación tiene que estar al pulgar.
El cuerpo principal debe vender.
```

## Test mínimo

1. Abrir la app.
2. Abrir Carniza.
3. Ver las acciones:
   - Armar oferta.
   - Vender urgente.
   - Ir a WhatsApp.
   - Volver a Inicio.
   - Salir de la demo / Cerrar sesión.
4. Probar Volver a Inicio.
5. Probar Salir de la demo en modo demo.
6. Probar Cerrar sesión en usuario real.
7. Confirmar que Crear oferta → WhatsApp sigue funcionando.
8. Confirmar que Vender urgente → WhatsApp sigue funcionando.
