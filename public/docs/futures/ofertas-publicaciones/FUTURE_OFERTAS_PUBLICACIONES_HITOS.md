# Future — Ofertas publicadas, historial e hitos comerciales

## Estado

```txt
Future importante
Cercanía: alta/media
Conexión con core actual: muy alta
```

## Problema que resuelve

Hoy AppPromos permite armar ofertas y vender por WhatsApp.

El próximo salto es recordar:

```txt
qué oferta se armó
cuándo se mandó
qué quedó sin enviar
qué promo se publicó
qué actividad tuvo la carnicería
```

## Objetivo

Transformar las ofertas en una historia comercial útil, sin hacer un panel pesado.

```txt
No alcanza con armar ofertas.
AppPromos tiene que saber cuáles se mandaron y cuáles quedaron dormidas.
```

## Alcance futuro

### 1. Historial de ofertas

Guardar información útil:

```txt
oferta creada
fecha
productos
total
origen: rápida / descuentos / urgente
estado: borrador / lista / enviada / guardada
```

### 2. Publicaciones / envíos

Registrar eventos simples:

```txt
enviada por WhatsApp
copiada
guardada como promo
reutilizada
publicada en web
```

### 3. Oferta lista sin enviar

Detectar situación clave:

```txt
Hay una oferta lista pero no se envió.
```

Carniza puede empujar:

```txt
La oferta ya está lista. Falta venderla.
[Mandar ahora]
```

### 4. Hitos comerciales

Ejemplos:

```txt
Primera oferta creada
Primer WhatsApp enviado
Primera promo guardada
Primera vez que usó Vender urgente
10 WhatsApps enviados
50 WhatsApps enviados
Web publicada
Primer cambio de precios
```

### 5. Panel Admin / seguimiento

En Admin puede verse:

```txt
última actividad
ofertas creadas esta semana
WhatsApps enviados
cliente sin actividad
prueba sin primer WhatsApp
```

## Valor comercial

Permite:

- ayudar al carnicero a vender más;
- detectar abandono;
- mejorar onboarding;
- crear mensajes de seguimiento;
- medir activación real;
- alimentar futuras recomendaciones de Carniza.

## Qué NO incluye por ahora

- tracking invasivo;
- panel de analítica pesado;
- métricas cada pocos segundos;
- IA real;
- promesas de venta automática.

## Regla de medición

```txt
Medir lo suficiente para decidir.
No armar un panel de la NASA.
```

## Frase guía

```txt
Lo rápido se manda.
Lo urgente se resuelve.
Lo promocional se guarda.
Lo que queda dormido, Carniza lo despierta.
```
