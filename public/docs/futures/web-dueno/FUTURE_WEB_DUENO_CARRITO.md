# Future — Web DUEÑO con carrito de compras

## Estado

```txt
Future importante
Cercanía: media/baja
Valor comercial para plan alto: muy alto
```

## Regla comercial

```txt
Todos tienen web propia.
DUEÑO tiene web personalizada con carrito.
```

## Web por plan

### Prueba gratis / ARRANQUE / SALVADOR

Web propia simple:

```txt
vidriera online
ofertas activas
lista de precios
imágenes genéricas automáticas
botón Pedir por WhatsApp
```

### DUEÑO

Web personalizada:

```txt
vidriera personalizada
imágenes propias
ofertas destacadas
lista de precios
carrito de compras
pedido armado por WhatsApp
```

## Objetivo

Darle al plan DUEÑO un diferencial real y entendible.

```txt
ARRANQUE = vendo rápido por WhatsApp
SALVADOR = vendo antes de picar y cuido margen
DUEÑO = tengo vidriera profesional con carrito de pedidos
```

## Flujo de carrito inicial

No hace falta pago online al principio.

```txt
Cliente agrega productos al carrito
↓
Revisa pedido
↓
Toca Enviar pedido por WhatsApp
↓
Al carnicero le llega ordenado
```

Ejemplo de mensaje:

```txt
Hola, quiero hacer este pedido:

- 2 kg Asado
- 1 kg Chorizos
- 1 kg Picada común

Total estimado: $ 42.500

Nombre:
Dirección:
Horario:
```

## Alcance futuro

- carrito simple;
- cantidades;
- total estimado;
- datos del cliente;
- envío por WhatsApp;
- imágenes propias solo en DUEÑO;
- destacado de ofertas;
- QR a la web;
- diseño más personalizable.

## Qué NO incluye al principio

- pago online;
- stock real;
- logística;
- delivery automático;
- sincronización avanzada;
- cupones;
- usuario final con cuenta.

## Riesgos

- aumenta soporte;
- puede generar pedidos fuera de horario;
- necesita disclaimers claros;
- precios deben estar vivos y bien publicados;
- debe aclarar que el pedido se confirma por WhatsApp.

## Frase guía

```txt
DUEÑO no es solo tener una web.
Es tener una vidriera con pedido ordenado.
```
