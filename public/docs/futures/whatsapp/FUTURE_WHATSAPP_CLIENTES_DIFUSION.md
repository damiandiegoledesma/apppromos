# Future — WhatsApp con clientes, etiquetas y difusión responsable

## Estado

```txt
Future importante
Cercanía: media
Riesgo: medio/alto si se implementa sin cuidado
```

## Origen

El antecesor A La Estaca ya tenía una idea más avanzada de WhatsApp:

```txt
combos seleccionados
contactos
etiquetas
vista previa
plantillas
campañas
consulta individual
```

## Problema que resuelve

Hoy AppPromos abre WhatsApp con una oferta lista.

A futuro podría ayudar a:

```txt
elegir a quién mandarle
usar contactos frecuentes
segmentar clientes
prearmar mensajes
reutilizar plantillas
```

## Objetivo

No convertir AppPromos en spam.

Sí ayudar a que el carnicero use WhatsApp de forma ordenada y responsable.

```txt
Oferta lista → elegir clientes → mensaje armado → enviar por WhatsApp.
```

## Alcance futuro

### 1. Contactos

Campos posibles:

```txt
nombre
WhatsApp
etiqueta
nota simple
último envío
```

Etiquetas:

```txt
Asado
Familia
Mayorista
Semana
Finde
Cliente frecuente
```

### 2. Selección de destinatarios

Opciones:

```txt
un cliente
varios clientes
por etiqueta
últimos clientes usados
```

### 3. Vista previa del mensaje

Antes de enviar:

```txt
ver texto
copiar
abrir WhatsApp
```

### 4. Plantillas

Ejemplos:

```txt
Promo del día
Promo para el finde
Oferta hasta agotar stock
Combo familiar
Aviso de lista de precios
```

### 5. Difusión manual responsable

No automatizar envío masivo.

No hacer spam.

No enviar sin acción humana.

```txt
AppPromos prepara.
El carnicero decide y envía.
```

## Cuidado legal/comercial

- no guardar datos sensibles innecesarios;
- no mandar mensajes automáticos sin permiso;
- no prometer campañas masivas;
- no usar WhatsApp como spam;
- evitar bloqueo de número por abuso.

## Ubicación futura

```txt
WhatsApp
Más → Clientes
Ofertas guardadas → Enviar a clientes
```

## Qué NO incluye por ahora

- API oficial de WhatsApp Business;
- bots;
- envío automático;
- scraping;
- importación masiva sin consentimiento;
- métricas pesadas.

## Frase guía

```txt
AppPromos no spamea.
AppPromos prepara mejor lo que el carnicero ya manda.
```
