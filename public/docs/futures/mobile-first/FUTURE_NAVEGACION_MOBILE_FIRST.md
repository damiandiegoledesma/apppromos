## Botonera inferior propuesta

```txt
[Inicio] [Precios] [Vender] [WhatsApp] [Más]
```

## Función de cada botón

### Inicio

Lugar para entender rápido:

```txt
qué hacer ahora
qué está pendiente
qué puede vender
```

### Precios

Abre Cambiar precios.

Tip central:

```txt
Poné precio a lo que vendés.
Lo que no vendés, dejalo en 0 y no aparece en tu web.
```

### Vender

Corazón comercial.

Abre:

```txt
Oferta rápida
Oferta con descuentos
Vender urgente
```

### WhatsApp

Acceso rápido a:

```txt
última oferta
retomar oferta lista
copiar mensaje
abrir WhatsApp
```

### Más

Todo lo secundario:

```txt
Mi cuenta
Mi web
Ofertas guardadas
Competencia
Ayuda
Panel Admin si corresponde
Cerrar sesión
```

## Regla

```txt
Vender = acción comercial inmediata.
Más = administración, configuración y módulos secundarios.
```

## Carniza

Carniza no reemplaza la navegación.

```txt
Carniza orienta.
La botonera mueve.
El cuerpo vende.
```

## Qué NO debe pasar

- header enorme;
- acciones escondidas arriba;
- cards gigantes;
- Carniza tapando precios/CTAs;
- demasiados textos;
- formularios largos sin pasos;
- botones difíciles de tocar.

## Resultado esperado

AppPromos debe sentirse como:

```txt
un mostrador digital
no una planilla
no un CRM
no un sistema de escritorio achicado
```
