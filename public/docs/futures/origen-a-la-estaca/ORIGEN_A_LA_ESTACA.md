# Origen — Carnicería A La Estaca

Este directorio conserva el **antecesor directo de AppPromos**:

```txt
index_v39_3.html
Carnicería A La Estaca
Venado Tuerto, Santa Fe
```

## Por qué se guarda

Antes de que AppPromos naciera como SaaS para carnicerías, existía una herramienta pensada para una carnicería propia: **A La Estaca**.

Ese archivo representa el origen operativo del producto:

```txt
carnicería real
mostrador real
precios reales
WhatsApp real
listas impresas
volantes
combos
material comercial
uso diario
```

## Qué valor tiene

No se guarda como código productivo para copiar y pegar.

Se guarda como:

```txt
cantera de ideas
memoria histórica
referencia de UX de mostrador
origen comercial de AppPromos
```

## Qué ideas salieron de ahí

- módulo de impresión de listas y volantes;
- historial de publicaciones/ofertas;
- WhatsApp más inteligente;
- material gráfico para redes;
- navegación mobile-first con botonera inferior;
- organización por módulos operativos/comerciales/sistema;
- lógica de combos, flyers y acciones rápidas.

## Regla

```txt
A La Estaca es la raíz.
AppPromos es la evolución SaaS.
```

No mezclar el monolito original con producción.

El archivo `index_v39_3.html` debe quedar preservado, pero no debe integrarse directo a `public/index.html`, `app.html` ni módulos vivos sin rediseño y adaptación.
