# Future — Material para redes, flyers, historias, posts y Reels

## Estado

```txt
Future importante
Cercanía: baja/media
No prometer todavía en landing
```

## Origen

El antecesor A La Estaca tenía piezas orientadas a:

```txt
flyers
historias
posts cuadrados
vista previa
prompts para IA gráfica
reels
reglas para no modificar productos ni precios
```

## Problema que resuelve

Muchos carniceros quieren publicar promos, pero no tienen tiempo ni diseño.

AppPromos podría ayudar a transformar ofertas reales en material para redes.

## Objetivo futuro

```txt
Elegís una oferta real.
AppPromos te arma el texto/prompt/pieza base para publicarla.
```

## Alcance futuro

### 1. Flyers simples

Formatos:

```txt
Historia 9:16
Post cuadrado 1:1
Flyer vertical
Imagen para estado de WhatsApp
```

### 2. Prompts para IA gráfica

Reglas obligatorias:

```txt
no cambiar productos
no cambiar precios
no agregar productos
no prometer cosas falsas
mantener nombre de carnicería
mantener WhatsApp
```

### 3. Reels

Ideas:

```txt
guion corto
texto en pantalla
voz sugerida
oferta del día
video simple de mostrador
```

### 4. Vista previa

Mostrar antes de exportar:

```txt
marca
oferta
productos
precio
leyenda
WhatsApp
```

## Por qué no va ahora

Puede abrir muchos frentes:

- diseño;
- generación de imágenes;
- derechos de imagen;
- peso de assets;
- promesas de IA;
- soporte al usuario;
- inconsistencias visuales.

## Regla de landing

No prometer “material pensado para vender” hasta que el módulo exista realmente.

## Planes posibles

```txt
SALVADOR:
textos y piezas simples

DUEÑO:
plantillas premium, marca más cuidada, imágenes propias
```

## Frase guía

```txt
Primero AppPromos vende.
Después AppPromos ayuda a mostrarlo más lindo.
```
