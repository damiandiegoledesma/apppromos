# AppPromos V12.18-B1 — Landing Primeros 50

## Objetivo

Reorientar la landing para captar las primeras 50 carnicerías activas, priorizando activación y uso real sobre pricing.

## Tesis comercial visible

- AppPromos = carnicería online conectada operativamente con WhatsApp.
- CTA principal: crear la carnicería online gratis.
- Sin plazo visible de 30 días.
- Sin pricing visible durante esta etapa de validación.
- Sin obligación de elegir plan ni cargar tarjeta.

## Cambios

- Hero más corto y orientado a conversión.
- Mensaje “Poné tu carnicería online. Gratis.”
- CTA principal directo al registro.
- Demo pasa a CTA secundario.
- Se presenta el flujo real: precios -> web -> carrito -> WhatsApp.
- Se elimina el bloque público de planes/precios.
- Se reemplaza por convocatoria “Primeras 50 carnicerías”.
- Las herramientas de ofertas aparecen como valor que el usuario descubre después de activar su web.
- Se actualiza detección de CTA de Analytics para los nuevos textos.

## No cambia

- Registro V12.18-A.
- Onboarding.
- Catálogo y precios.
- Web pública.
- Carrito.
- WhatsApp.
- Planes internos o lógica de acceso/pagos.

## Testing

1. Abrir landing desktop y mobile.
2. Verificar CTA principal en hero.
3. Verificar que no aparezcan precios de planes ni “30 días”.
4. Click “Crear mi carnicería gratis” -> registro.
5. Click “Ver cómo funciona” -> demo.
6. Iniciar sesión desde landing.
7. Confirmar que registro sigue funcionando.
8. Revisar consola sin errores rojos.
9. Confirmar eventos GA4/console para CTA de registro y demo.
