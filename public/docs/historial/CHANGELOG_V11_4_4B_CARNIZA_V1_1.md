# CHANGELOG — V11.4.4B Carniza V1.1 Contextual Real

## Objetivo
Mejorar los textos de Carniza V1.1 sin perder la arquitectura ya aprobada en V11.4.3.

## Cambios incluidos

- Mantiene la lógica buena existente de Carniza:
  - integración con `access-control-service`;
  - WhatsApp real de AppPromos;
  - navegación por paneles reales;
  - `escapeHtml` de seguridad;
  - ocultamiento en `guest` y `usersPanel`;
  - `updateCarnizaContext`.
- Ajusta textos para que Carniza le hable solo al carnicero.
- Elimina frases internas o técnicas.
- Refuerza el enfoque comercial: Precios → Ofertas → WhatsApp.

## No incluido

- No toca Firebase.
- No toca `app-main.js`.
- No toca CSS.
- No incorpora IA, Python ni Gemini.
