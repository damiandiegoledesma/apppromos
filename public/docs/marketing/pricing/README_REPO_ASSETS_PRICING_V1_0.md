# AppPromos — Material aprobado para repo — Pricing V1.0

Este paquete contiene los assets visuales aprobados para el pricing de AppPromos.

## Carpeta de destino sugerida

```txt
public/assets/marketing/pricing-v1/
```

## Carpeta de soporte/documentación sugerida

```txt
docs/marketing/pricing/
```

## Regla central

- Todos los planes tienen web propia.
- DUEÑO tiene web personalizada.
- SALVADOR es el recomendado.

## Piezas incluidas

1. Prueba gratis 30 días.
2. ARRANQUE.
3. SALVADOR oscuro/dorado.
4. SALVADOR claro alternativo.
5. DUEÑO.
6. Resumen global de planes.

## No usar todavía como reemplazo automático

Estos assets quedan aprobados como material comercial y de repo, pero no implican reemplazar la landing actual en producción de inmediato.
La Landing V2.0 se evaluará más adelante.
